# Geminiへの送信量の上限（P1）

候補を低解像度にしても、合計尺・バイト数・文字起こし量が大きくなる場合があります。外部送信の前に、実際の候補と送信データを検査します。

| 設定JSONの項目 | 既定値 | 検査する量 |
|---|---:|---|
| `max_analysis_seconds` | 600 | 候補区間の合計秒数 |
| `max_analysis_coverage` | 0.5 | 合計秒数 ÷ 元動画の秒数 |
| `max_preview_bytes` | 26214400（25MiB） | プレビュー1本の実ファイルサイズ |
| `max_analysis_bytes` | 104857600（100MiB） | 全プレビューの実ファイルサイズ合計 |
| `max_prompt_text_bytes` | 65536（64KiB） | テキストpartsのUTF-8バイト数合計 |

比率は0より大きく1未満、その他は正の値に制限します。`candidates`・`min_seconds`・`max_seconds` による件数・区間検査も維持します。設定値の最大の組み合わせではなく、実際の候補区間を判定します。

## 判定と停止位置

- 重複する候補も、重なった秒数を候補ごとに数えます。候補全体の和集合ではありません。
- 新規候補とキャッシュから復元した候補の両方を検査し、秒数・区間・テキスト量の超過はプレビュー作成前に停止します。選定結果までキャッシュされていても、この検査は省略しません。
- プレビューは1本できるごとにサイズを検査し、超過時は後続のプレビュー作成を止めます。作成途中を含むプレビューを後処理で削除します。
- `selection.choose` は単独で呼ばれても、SDKのimport・Client作成・最初のuploadより前に、全候補の時間・件数・テキスト・ファイルサイズをまとめて検査します。
- テキストは計測した文字列そのものを送ります。指示文・候補ID・尺の説明・ASRを含み、同じASRが複数の候補に入ればその回数分を数えます。モデル名・JSONスキーマ・動画・通信形式の付加情報はこのテキスト上限には含みません。
- 各プレビューのサイズとSHA-256を事前に記録し、各uploadの直前にも照合します。成功時の `selection_receipt.analysis_budget` に実測値と適用した上限を、`visual_inputs` にファイルごとのサイズ・SHA-256を残します。本文やAPIキーは記録しません。

上限ちょうどは許可し、超過を許すための誤差は設けません。候補の自動削減、比率の自動緩和、再試行、別モデルへの切替は行いません。時間の上限に達した場合のエラーには合計秒数・上限と、`candidates` または `max_seconds` の調整案を表示します。

## 短い動画・手動編集

75秒の候補を1本送る場合でも、既定の比率では元動画が150秒以上必要です。元動画が短ければ、`config.example.json` をコピーして `candidates`・`max_seconds` を明示的に小さくしてください。`clips <= candidates` と `min_seconds < max_seconds` も満たす必要があります。動画が `min_seconds` の2倍未満なら、既定比率では最低尺の候補1本も収まりません。

`cut` と `run --selection-file` はGeminiに送らないため送信予算を適用しません。手動選定の区間検査や入力検査は従来どおり行います。

## 再開・既存成果物

入力SHA-256・設定全体・実装ハッシュによる既存の照合を弱めません。上限設定の変更、またはこの修正前のコードで作成した出力先では `--resume` を拒否します。旧出力の削除・書き換え・自動移行はしません。既存成果物を保存したまま、新しい出力先で処理してください。

以前成功した36秒のGemini合成素材ジョブは旧コードでの経路確認です。今回の比率制限を満たすことを意味しません。同じ動画でのAPI生成は再実行していません。

## 提案と検証の区別

Antigravityの `claude-opus-5-5-high` に設計提案だけを依頼しました。P1レビューIDは `b4c85c37ce944e4eb83be51773e0a97c`、追加提案IDは `301fc0823b564177a757e87e2d12d2c2`。Opusは編集せず、主担当がコードと照合して実装しました。比率1.5の案や、設定上の候補数×最大尺だけで拒否する案は採用していません。

APIなしの回帰テストで、秒数・バイト数の境界、重複の二重計上、日本語UTF-8、送信文字列との一致、後続プレビューの超過がSDK import前に止まること、プレビュー作成前の停止、キャッシュ再検査、後処理、手動経路の除外を確認します。大きいファイルの検査は疎ファイルで行い、動画生成は不要です。

これらはClipForge独自の送信上限です。Gemini公式のquotaやトークン上限、課金額、無料枠内の利用を保証しません。実配信素材での品質は別途確認が必要です。
