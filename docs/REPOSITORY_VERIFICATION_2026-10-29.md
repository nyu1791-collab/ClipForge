# リポジトリ確認記録（2026-10-29）

利用者の依頼で実施した、PC 移行準備に伴うローカルの確認記録。実際の制作、モデル要求、Colab GPU の確保、Actions の投入、Drive への移動・納品は行っていない。結果を映像・字幕の品質確認や、Windows 実機での成功と混同しない。

## セットアップ

- Python 3.12・uv 0.12.23 の現環境で確認。FFmpeg、ffprobe、Noto Sans CJK JP、Colab 制御 SDK は存在した。
- 空の Ubuntu 24.04 コンテナにリポジトリをコピーし、root で `bash setup.sh` を実行した。Ubuntu の依存、公式の uv インストーラー、Python 3.12、ロック済みの基本依存の導入まで完了した。実行したセットアップのコードは `278acde` 時点。
- Windows 11・WSL2 のインストール、Windows 実機上の非 root ユーザーによる sudo、GitHub 認証、追加の `--dev` 経路は未確認。インターネットとパッケージ取得元の可用性は保証しない。

## テスト

基準版は PC セットアップ等の変更前の `9d06534`。基本命令は `uv run --no-sync python -m pytest -q -p no:cacheprovider`。基準版は別作業ツリーで同じ仮想環境を使用し、その作業ツリーの `src` を指定した。モデルと外部制作サービスは呼んでいない。

| 対象 | 成功 | 失敗 | 補足 |
| --- | ---: | ---: | --- |
| 基準版 `9d06534` | 1,304 | 212 | 1,516件。現行の再試行仕様と一致せず、実時間の待ちが発生する旧テストを含む |
| 更新後 `b7d7d6d` | 1,332 | 186 | 1,518件。確認画面の新規テスト2件を含む |

失敗したテスト名を比較し、基準版にない新たな失敗はなかった。基準版で失敗した26件は、再試行・HIGH・4窓の現行仕様に合うようテストを直した結果、対応する更新後のテストが成功した。Kick のテスト48件、確認画面・修正・回収・Transcribe の選択テスト51件、新しいローカル確認サーバーの2件も個別に成功した。

ローカル確認サーバーでは、画面に埋め込まれた字幕・長さが元の選定・字幕データと一致するかの照合を追加した。合成データで不一致の拒否、HTTP の部分取得、修正の保存、別オリジンと別の親データの拒否を確認し、既存の編集用 ZIP もコード上で受け付けることを確認した。動画を実際に目視・聴取したことや、スマホ・iPad のブラウザーで動くことを意味しない。描画は行っていない。

残る186件は未解決で、すべてを無害な旧テストと断定しない。例えば品質ゲート廃止後も旧判定を期待するもの、旧投入・旧回収の mock が現在の認証や経路と合わないもの、OpenCode 実行ファイルが見つからない環境に依存するものを含む。個別に旧仕様との違い、環境不足、実装の不具合を切り分ける必要がある。失敗を理由に本番を自動実行・再投入しない。

## lint・形式

- `uv run --no-sync ruff check .` は基準版と更新後のいずれも88エラー。ファイル・エラー種別・メッセージを比較して増減はなかった。主な内訳は既存 `tools/clipforge_drive_delivery.py` の83件など。
- 今回変更したサーバーとテスト6ファイルの `ruff check` および `ruff format --check` は成功した。
- `main` との差分に含まれる Python ファイル全体の `ruff format --check` は8ファイルが未整形。今回の変更前から含まれるファイルで、一括整形はしていない。

## 統合の扱い

この確認は main 全体の合格を意味しない。下書き PR の統合前に、未解決の失敗と必要な検証範囲を判断する。実素材での字幕の完全性や話者の正確さ、販売・公開の許可は別に確認する。
