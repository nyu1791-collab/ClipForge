# Transcribe試作とLOW整文の比較

対象は保存済み1話題（約795.8秒）。既存の文字起こし・同一音声・同一整文プロンプトを使い、先行MEDIUM応答と新しいLOW応答を比較した。LOWは新たに1回実行し、空白箇所を前後付きでTranscribeに1回かけた。モデルの応答と編集データは非公開保存し、人による聴取は行っていない。

- MEDIUMは73.89秒、LOWは23.83秒。異なる時刻の単発実行であり、速度の恒常的な比率は保証しない。
- 元の81個の発話IDに対し、MEDIUMは81件、LOWは79件を返した。LOWの未返却2件は元文字を表示する既存のフォールバックが適用された。件数は内容や品質の証明ではない。
- 両者の話者割当は16 IDで異なり、LOWは話者2のラベルを出さなかった。元音声の聴取による正解は未確認で、いずれが正しいかは断定できない。話者の一貫性を重視し、字幕整文は話題単位のMEDIUMを選択。チャンク整文やHIGHは今回実行していない。
- 元の文字起こしにはクリップ内288.1〜482.5秒に発話がない。283.1〜487.5秒を再送すると元の空白内に51語が返った。再送は2.319秒。発話候補があったことはモデル出力の比較であり、再認識された語と時刻が実音声に正しいとは確認していない。
- 当該空白の音声の全体RMSは-30.4 dBFS、1秒RMS最大は-17.2 dBFS。音量だけで発話・BGM・環境音は識別できない。
- 参考音声はユーザーのDrive上の既存の動画フォルダに保存した。これは直接の人手聴取や字幕監査を行ったことを意味しない。
- 空白補助と単語時刻の保持は今回の実行後に実装した。外部通信なしの関連テストで確認し、実素材での新コードの総合実行と、動画全体の同期・話者・字幕精度の確認は未実施。
