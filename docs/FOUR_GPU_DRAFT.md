# 4 GPU並列化の作業案

このブランチは作業案であり、テスト・実GPU検証・本番反映はしていない。

- 採用話題を最大4組へ分配し、それぞれ別のColabランタイムで文字起こしする。
- 通常制作の描画はクリップ単位で最大4本並列に実行し、非公開の部分結果を統合する。
- 話題またはクリップが4件未満の場合は、その件数が並列数の上限となる。単一の話題・クリップは分割しない。
- render-onlyの既存経路は並列化していない。
- 部分的に失敗・中断した場合は、保存された依頼状態と非公開結果を確認する。ASRの未完了部分を自動で再送・復旧する機能はない。
- 部分描画の依頼マーカーと結果Releaseは再送防止・復旧のため保持する。後片付けの手順は未整備。
- GPU割当数はColabの実際の容量に左右され、4台の確保は保証されない。

採用前には、同一性、GPU解放、部分失敗・中断からの復旧、保存と統合、実際の割当を含む検証が必要。
