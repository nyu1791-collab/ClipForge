# 許諾済み素材の切り抜き方針

ClipForge で切り抜く素材を選ぶ時の判断メモ。**制作経路に工程を足さず、品質ゲートや自動検査も増やさない。** 制作の手順は `docs/QUICK_START.md` と AGENTS.md に従う。法的助言ではない。YouTube の記述は 2026-11-01 に公式ヘルプで確認した。

## 1. 対象

使ってよいのは次の素材だけ。

- 自分が権利を持つ素材
- 権利者本人の依頼で作る素材（配信者、ポッドキャスト、ウェビナー、企業など）
- 権利者から、二次編集と用途を明示した許諾を書面で得た素材

第三者の配信の無断切り抜き、転載、字幕を足しただけの量産はしない。URL を取得できることは、使ってよいことを意味しない。

## 2. 許諾について記録すること

依頼ごとに、最初に一度だけ書き留める。

- 権利者または署名者
- 対象（チャンネル、配信、アーカイブ）
- 二次編集と商用利用の可否
- 公開先、地域、期間
- 収益の分け方
- 取り消しと削除の条件
- 素材の中の別の権利（BGM、ゲーム映像、ゲスト、画像）

記録は依頼者の情報を含むので、公開リポジトリに入れない。

`クレジット表記`、`出典表記`、`概要欄の URL` は許諾の代わりにならない。YouTube も、他者の素材の収益化には商用利用を認める明示の書面許可を求めている（[収益化と権利](https://support.google.com/youtube/answer/2490020?hl=ja)）。

## 3. 権利と収益化は別に考える

**許諾があっても、媒体の収益化条件を満たすとは限らない。**

- YouTube の再利用コンテンツの方針は、元の作者の許可があっても適用される。著作権の判断とも別で、元動画との意味のある違いが求められる。独自の解説、批評、物語の構成は例に挙げられている（[収益化ポリシー](https://support.google.com/youtube/answer/1311392?hl=ja)）。
- 字幕・クロップ・ズーム・効果音だけで十分とは考えない。
- テンプレート的な量産は inauthentic content の対象になり得る。候補が似通っていたら本数を減らす。
- TikTok の Creator Rewards は原作性を求める。許諾を得た他者の映像が対象になるとは考えない。条件はアプリと公式の案内で確かめる（2026-11-01 は検索結果の抜粋のみ確認。[FAQ](https://www.tiktok.com/support/faq_detail?id=7581821550694013452&category=web_account)）。

## 4. 人が決めること

次は自動化しない。

- 最初の許諾の確認
- 素材に第三者の権利が含まれる時の最終選択
- 公開と収益化の設定（AGENTS.md の公開の扱いに従う）
- 申し立てや異議への対応

見どころの選定、字幕、描画は既存の経路に任せる。モデルの判断で権利の判断を上書きしない。

## 5. 公開を止める場面

次のどれかに当たれば、公開しない。止めるのは公開だけで、制作物は保持する。

- 許諾がない、切れた、取り消された
- 申し立てや Content ID が未解決
- 媒体から警告を受けた
- BGM・ゲーム映像・ゲストの権利が不明
- 法的な扱いが曖昧で、権利の立場が定まらない

## 6. 売り方の優先順

媒体の広告収益に頼らない。

1. 制作費（月額、本数単位）。依頼者が権利者なので関係が単純で、媒体の収益化条件を満たす前でも売上になる
2. 基本料金＋成果報酬（明確な指標がある時）
3. 書面契約のある公認チャンネルの収益分配
4. 広告収益（追加分として）

例：「2 時間の配信を、見どころ・字幕・縦型の候補に。最終公開は本人が承認」。
