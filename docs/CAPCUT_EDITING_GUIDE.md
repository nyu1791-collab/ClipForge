# CapCut 仕上げガイド（任意）

ClipForge の縦型ショートを CapCut で仕上げる時の手引き。**使うかどうかは好みで決める任意の補助で、合格基準でも停止条件でもない。** 全部やらなくてよい。字幕の言葉の直し方は[編集ルールブック](../src/clipforge/prompts/gemini_editorial_rulebook_ja.md)が唯一の基準で、ここでは繰り返さない。確認日は 2026-11-02。

表記：**[公式]** 公式ページの本文で確認／**[実測]** 研究の結果／**[経験則]** 一般的な経験で裏付けなし／**[要確認]** 公式で確かめられず、お手元の画面で確かめたいもの。CapCut の公式ページは版を明記していないため、**9.7 でのボタン名と場所はすべて画面で確かめる**。公式の表記は英語版。

## 1. 5分の仕上げチェック

動画を一度、音ありで最後まで再生しながら進める。

**冒頭3秒（約1分）**
- [ ] 最初の一言で、何の話か伝わるか。切り出しの先頭には約0.3秒の余白がある。
- [ ] 前置きが長ければ、話の始まりまで切る（3章）。

**見出し（約30秒）**
- [ ] 見出しは別の文字として上に入る。見出しの情報がないクリップでは入らないので、その時は `heading.txt` を開き、文字ツールで手で足す。
- [ ] 中身と見出しが合っているか。基準はルールブック10章。
- [ ] 20文字前後だと 360×640 では2行になりやすい。2行で読めれば十分。

**字幕（約2分）** 実際の出力で見かけた形を含む。
- [ ] 漢字の誤変換：同じ読みの別の語、配信の分野の専門語。
- [ ] 名前：人物、商品、作品。確信がなければ変えない。
- [ ] 数字：桁、単位、「約」「くらい」。2万と20万のような違いは耳で確かめる。
- [ ] 否定：「〜じゃない」「〜ない？」が肯定に化けていないか。語尾の「？」で意味が変わる短文に注意。
- [ ] 句読点：生成字幕は「、」を**全角の空白**で表し、文末の「。」を付けない仕様。これは誤りではない。直すなら行末に余った空白や、空白の入れ忘れ。
- [ ] 改行：次のような箇所は読みにくい。助詞1文字だけの行、1文が2つの字幕に割れている、数字と単位が別行。
- [ ] タイミング：言う前に文字が出ない、声が終わって長く残らない。短い一言は一瞬で消えやすい。
- [ ] 言い淀みの残り：意味のないものだけ消す。迷ったら残す（ルールブック2章）。
- [ ] 意味の通らない短い断片：聞き取り違いのことが多い。音を聞いて直し、分からなければそのまま残すか字幕を「［聞き取り不明］」に。

**音・終わり・書き出し（約1分30秒）**
- [ ] 音：スマホかイヤホンで、声が聞きやすいか、効果音が声に被らないか。ClipForge の映像は音量処理済みで、効果音が入っていることもある。
- [ ] 終わり：語尾や笑いが途中で切れていないか（末尾に約0.5秒の余白あり）。オチの後の間延びは詰める。
- [ ] 書き出し：解像度は4章、形式は MP4。fps は元のままで上げない。

## 2. CapCut での字幕編集

### 再生しながら1つ直す
1. タイムラインの字幕をダブルクリックするか、右クリックして "Edit Captions" を選ぶ。**[公式]**
2. 直したい行をクリックして打ち直す。変更は自動で保存される。**[公式]**
3. 止める・再生するはスペースキー、1コマ送りは矢印キー、戻すのは Ctrl+Z。**[要確認]**

コツ **[経験則]**：誤りに気づいたら止め、その場で直してすぐ続きを再生する。1文字ずつ悩まず、怪しい所は後で1回まとめて聞き直す。

### 分ける
1. 字幕を選び、分けたい位置に再生位置を置いて Ctrl+B、または右クリックして "Split"。**[公式]**
2. 分けた後の文字は、前後それぞれ必要な部分だけに直す。**[要確認]**
3. 分けられない時：再生位置が字幕の範囲外／0.2〜0.3秒ほどより短い／グループ化されている（右クリックして Ungroup）／字幕の処理中。**[公式]**

### つなげる・長さを変える
公式の説明は見つからなかった。**[要確認]** 一般的には、後ろの字幕の文字を前へ移して後ろを消し、前の字幕の右端をドラッグして伸ばす。長さの調整も端のドラッグで行う。

### まとめて見た目を変える
- 編集パネルの "Select" を押し、Ctrl で飛び飛びに、Shift で範囲を選ぶ。**[公式]**
- 選んだ行に "Style" で字体、大きさ、色などを設定する。**[公式]**
- **注意：**選んだ状態で "Edit" から文字を入れると、選んだ**全行が同じ文字**になる。**[公式]** 見た目の変更だけに使う。
- 全字幕に一度で反映する "Apply to all" もある。ただし公式の説明が割れている。読み込みの手順では使えるとあり、別のページでは自動字幕だけが対象とある。**[要確認]** ClipForge の字幕は読み込みなので、効かなければ複数選択で設定する。
- 分割や時間調整の後に足された字幕には反映されないことがある。**[公式]** **先に文字とタイミングを直し、見た目は最後に**すると手戻りが少ない。
- 字幕をきれいにするために自動字幕を作り直すと、ClipForge の整文が失われる。やらない方が無難。

### UI に隠れないようにする
- 一番確かなのは**投稿画面のプレビュー**で見ること。隠れる範囲は媒体、端末、広告の有無で変わる。
- CapCut 内にガイド線を出す機能は公式で確認できなかった。**[要確認]**
- 参考：Meta の Reels **広告**の案内では、上約14%、下約35%、左右約6%を避けるとある。**[公式・画像広告向け]** 360×640 なら上90px、下224px、左右22px。通常投稿の値ではなく、目安として使う。
- ClipForge の既定は、字幕の下端が画面の下から約12%（約77px）、見出しが上から約6%。投稿画面で隠れるなら、字幕を少し上へ動かす。YouTube と TikTok の通常投稿の数値は公式で確認できなかった。**[要確認]**

### 360p で読める大きさ
- ClipForge の既定の字幕は高さの約4.8%（360×640 で約31px）、太字、白文字に黒縁、1行は約10文字まで。**これより小さくしない程度**が目安。細い字体や薄い縁は潰れやすい。**[経験則]**
- CapCut の大きさの数値は px と同じとは限らない。**[要確認]** 数値より、プレビューをスマホの画面くらいの大きさにして読めるかで判断する。

## 3. 維持率を上げる工夫

最初に正直な結論：**配信の切り抜きで、下の手法ごとの維持率の上昇を実測した公開研究は見つからなかった。** 「○秒ごとに切ると△%伸びる」といった数字は、調べた範囲では根拠をたどれなかったので載せない。自分の YouTube の維持率で確かめるのが確実。

### 実測・公式で言えること
- YouTube は「視聴 vs スワイプ離脱」で、見た人と離れた人の割合を示す。エンゲージビューは最初の数秒を超えて見られた回数で、ループは含まない。**[公式]**
- 維持率の説明では、冒頭が高いのはサムネイルとタイトルの期待に中身が合っている兆しとされる。繰り返し再生された山は、良い内容のほか分かりにくさの場合もある。**[公式]** ただしこの説明はショート専用ではない。
- TikTok の**広告**向け案内は、最初の3秒で内容を示し、最初の6秒でフックを優先するよう勧める。**[公式・広告向け]** 通常投稿の基準ではない。
- ジャンプカットの実験（Dost & Huang 2026、242人）**[実測]**：無音や言い直しを詰めたカットは、中程度以上の頻度の時だけ、未編集より「いいねしたい」が上がった（視聴継続の意向は有意差なし）。音を少し重ねるカットは視聴継続の意向を上げたが、高頻度では差がなくなった。結論は「速ければ良いわけではない」。参考にした TikTok 50本のカット数は中央値で毎秒約0.33回（約3秒に1回）、範囲は毎秒0.13〜0.82回。
  - **限界：**約20秒の解説動画1本を元にした、便宜的な標本の自己回答。配信の切り抜きにそのまま当てはまるとは言えない。

### 手法ごとの使いどころ（以下は [経験則]）

| 手法 | 使う時 | 使わない時 |
|---|---|---|
| フックの選び方 | 話の核心や驚きが早く分かる場面から始める。見出しと同じ話題にする | 本編にない結末を匂わせる。後半のオチだけ先に流して順序を変えて誤解させる |
| 無音を切る | 待ち時間、操作だけの間、言い直し | 溜め、驚いて固まる間、笑いの余韻。**字幕がない＝無音ではない**ので必ず聞く |
| ジャンプカット | 話が同じ所を回る時、前置きが長い時 | 間そのものが面白い時、話者が同時に話す時、否定や条件が抜ける時 |
| ズーム | オチや決定的な一言に1本で1〜2回程度 | 毎文。元が低解像度なので、大きく寄せるほど粗く見える |
| 表情を見せる | 顔の反応が要点の時。見せたい対象と顔の配置を決めておく | 配信画面の情報が要点で、切ると話が分からなくなる時 |
| 強調語 | 数字や固有名詞など、1本で数か所。色や太さで | 発言を言い換えた文字、盛った文字。文言の基準はルールブック |
| 効果音 | 映像に入っていなければ、ツッコミの直後などに少しだけ。目安はルールブック7章 | 毎文、深刻な話。映像の効果音に重ねる |
| 終わりとループ | 最後の一言が自然に冒頭へ戻る時だけ | 途中で切って無理にループさせる、オチを隠す |

実サンプルでは、字幕のない間が数秒続く箇所が複数あり、最長は約7.6秒だった。まずここを聞き、削るか残すかを決めると効きやすい。カットの後は字幕の位置がずれていないかを見る。映像だけ切ると字幕がずれるので、字幕も一緒に切る。**[要確認]**

## 4. 書き出し設定

**おすすめ：普段は 360p のままでよい。特に見せたい1本や納品する1本だけ 720p にする。1080p はほぼ不要。**

- **360p の良さ：** 字幕直しが軽く、書き出しも速く、このノートPC（16GB、内蔵GPU）に合う。CapCut も書き出しが重い時は解像度、fps、ビットレートを下げるよう案内している。**[公式]**
- **360p の弱点：** 投稿後に媒体側でさらに圧縮されて粗く見えることがある。**[経験則]** 媒体が低解像度をどれだけ強く圧縮するかの公式な数字は確認できなかった。投稿して見比べるのが確実。
- **アップスケールで細部は増えない。** 元が最大360pなら、映像の情報は増えない。
- **720p で良くなるもの：** まず、CapCut が描く字幕と見出しの文字がくっきりする。次に、既定の配置（fit＋ぼかし背景）では横長 640×360 の元映像を幅360へ縮めて入れているが、720×1280 なら幅720に入るので縮小で失う分がなくなる。ただし、**これが活きるのは 720p で描画した映像（`clean-720p.mp4` がある場合）を使う時**。360p の映像のまま 720p で書き出すと、良くなるのは主に文字だけ。CapCut で映像を差し替える手順は **[要確認]**。
- **1080p：** 720p より良くなるのはほぼ文字の細かさだけで、書き出しは重くなる。YouTube ショートの上限は 1080p。**[公式]** 依頼先の指定がある時だけで十分。
- **媒体の目安：** TikTok の広告向け案内は 720p 以上を勧めている。**[公式・広告向け]** 通常投稿の基準ではない。Instagram の公式ヘルプ本文は確認できなかった。**[要確認]**

### 書き出し画面で見る所
右上の "Export" から、解像度、fps、形式を選ぶ。**[公式]**

| 項目 | 普段 | 大事な1本 |
|---|---|---|
| 解像度 | 360p（一覧になければ一番低いもの **[要確認]**） | 720p |
| fps | 元のまま | 元のまま |
| 形式 | MP4（H.264） | MP4（H.264） |
| ビットレート | 既定 | 高め。"Bit rate" を "Custom" にして Kbps を指定することもできる。上げると画質を保ちやすい。**[公式]** 具体的な値は根拠がないので、見比べて決める |

別の媒体に投稿した版から作り直さず、書き出した元の動画を残す。

## 5. トラブルを避ける

- **ドラフトのフォルダを動かさない。** 映像はドラフトの中にコピーされ、そのフォルダの場所を参照する。元のクリップは動かしても開けるが、CapCut の保存先にあるドラフトのフォルダは移動、改名、削除をしない。
- **保存場所：** CapCut は、外付けドライブやクラウド同期フォルダから直接読み込まず、PC 内のフォルダに置くよう案内している。**[公式]**
- **ドラフトを作る前に CapCut を閉じる。** 開いたままだと作成できない。`tools\capcut.ps1` の `open` で起動、`status` で「動いているか」を確認できる。ターミナルが苦手なら Claude に「CapCut の status を見て」と頼めばよい。
- **電源：** 書き出しと長い作業は電源につなぐ。バッテリー節約で遅くなりやすい。**[経験則]** 他の重いアプリは閉じる。**[公式]**
- **プレビューが重い：** プロキシは軽い代わりに、大きさやぼかしの見え方が実際と違うことがある。**[公式]** 切り替える場所は公式ページで2通りあり（Project Settings と Menu > Settings > Performance）、9.7 での場所は **[要確認]**。元が 360p ならプロキシなしでも動くことが多い。**[経験則]**
- **書き出しが止まる：** 順に試す。CapCut と PC の再起動 → 空き容量の確認 → プロジェクトを複製して書き出す → 解像度などを下げる → Settings > Performance でハードウェアアクセラレーションを切る。**[公式]**
- **ドラフトが開かない時：** ドラフトは非公式ツールで作っており、CapCut の版で開けないことがある。MP4 と字幕は無事なので、手で読み込めば続けられる。
  1. CapCut で新規プロジェクトを作り、比率を 9:16 にする。
  2. "Import" で `video.mp4`（または `clean-360p.mp4` など字幕のない映像）を入れて、タイムラインへ置く。
  3. "Captions" > "Add Captions" > "Import file" で `captions.srt` を選ぶ。**[公式]** 別のページでは Text > Auto Captions > Local captions とある。画面に合うほうで。
  4. `heading.txt` の見出しを文字ツールで足す。
- 読み込めない時は SRT が UTF-8 か確かめる。**[公式]** 自動制作をやり直す必要はない。

## 6. 権利

詳しくは[許諾済み素材の切り抜き方針](AUTHORIZED_CLIPPING_POLICY.md)。公開してよいかの判断はこの方針に従い、このガイドの項目には含めない。**媒体の規則は変わるので、投稿前に公式を見る。**

- 使うのは、自分の素材、権利者の依頼による素材、書面で許諾を得た素材だけ。
- クレジットや概要欄の URL は許諾の代わりにならない。付いているクレジットは消さない。
- YouTube の再利用コンテンツの方針は、元の作者の許可があっても適用される。独自の解説や意味のある違いが求められ、当てはまるとチャンネル全体の収益化に影響することがある。**[公式]**
- Instagram は、他のアカウントからの再投稿や透かし入りのリールは、おすすめされにくいと案内している（2023年のページ）。**[公式]**
- TikTok の収益化は条件をアプリと公式で確かめる。本文を確認できなかったので、ここでは書かない。
- 再利用の検出を避けるための加工はしない。誇張や誤解を招く見出しにもしない。収益化は媒体頼みにせず、方針メモ6章の順を参考にする。
