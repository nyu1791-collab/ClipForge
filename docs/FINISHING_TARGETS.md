# 字幕・音・描画の仕上げ目標

以下は仕上がりを整えるための目安。合格基準・停止条件ではない。少し外れたことや補助処理を適用できなかったことを理由に、strictエラー・追加モデル要求・自動再生成・監査へ進めない。

| 対象 | 落とし込む工夫と目安 | 判断しにくい・目安に届かない場合 |
|---|---|---|
| 60秒の継ぎ目 | 境界前後1.5秒付近、隣り合う窓、近い時刻で重なる同じ発言だけ統合する | 別話者、数字や否定が違う、短い返答、単なる類似文は消さず残す |
| 字幕の時刻 | 採用音声だけを軽くデコードし、20ms単位のエネルギーから得た近傍境界へ最大±0.5秒の小幅な補助を行う | 音楽・雑音・一定の音量等で境界が曖昧、補助デコード不能、近くに境界がない場合はGemini推定を使う |
| 日本語の改行 | 既存の禁則・語句・数字のまとまりに加え、形態素上の助詞を前の語へつなげる | 極端に長い語などは表示できる折り返しを使い、文字を削除したり制作を止めたりしない |
| 短い字幕 | 同じ話者の自然なまとまりを作り、表示0.8〜1.0秒程度を目指す。延長処理の目安は0.8秒 | 次の発言・話者交代・クリップ末尾を優先し、余地がなければ短いまま表示する |
| 無音での居残り | 元発言の終了からの読み取り用延長を最大約1.5秒に抑える | 発話そのものが長い場合を「1.5秒で切る」処理にはしない。次の字幕より後へ延長しない |
| 切り出し | 初回選定時に開始−0.3秒・終了＋0.5秒程度の余白を取り、元配信の範囲内へ収める | 元配信の冒頭・末尾では取れる余白だけ使う。尺や重複の目安を理由に拒否しない |
| 会話の音量 | 描画内の1パスloudnormの目標をI=−14 / TP=−1.5 / LRA=11とし、既存の保守的なリミッターを維持する | 出力の実測値の達成を保証せず、未達による再測定・補正・再描画は行わない。YouTubeの一律必須規格とは扱わない |
| 効果音と声 | 声の通常処理後に低音量のSEを加え、声が鳴るときはSE側をサイドチェインで抑える | SEの数・聞こえ方で品質不合格にしない。会話の音量をSEに合わせて下げない |
| 文字の解像度 | 素材は最大360p取得を維持。映像をキャンバスへ拡大してから字幕・見出しを焼き付ける。既定720p、プレビュー360p、指定時1080p | アップスケールで元映像の細部が復元したとは報告しない。360pを選んだことを品質エラーにしない |
| 見た目の参考画像 | 描画済み動画から通常字幕・強め演出など実在する最大3場面を抜き、クリップごとの一覧JPEGを作る | 演出のない動画に見本を捏造しない。画像生成・単体画像アップロードができなくても動画の保存を続ける |
| 修正・再開 | 保存済み字幕・時刻・演出への明示パッチを、共通render-onlyへ渡す | 修正済みの時刻へ自動で波形補助や余白追加を再適用せず、Geminiへ戻らない |

## 補助処理と実行エラーの区別

重複整理は隣接する窓の境界だけに限定し、一定以上の長さ・時刻の重なり・本文の包含・類似度に加えて、話者・数字・否定の違いを見て保守的に行う。別の発言かもしれない場合は残す。「全編の反復削除」は復活させない。

音声エネルギーは発話内容を認識するものではなく、音楽や環境音を声から確実に分離できない。Silero等の追加モデルやWhisperを使わず、採用音声だけの軽いRMS補助とする。単語時刻精度・強制アライメント・リップシンクの達成を保証しない。適用状態はreceiptの `subtitle_display[].finishing` に残し、未適用を不合格にしない。

もともと重なっていない隣接字幕は、直前字幕の補正後の終了時刻も考慮し、補助処理によって新しい重なりを作らない。元からある同時発話は、この処理で無理に解消しない。

切り出し余白は選定時に一度だけ加え、元の選定時刻と余白後の時刻を `clip_safety_margins` に残す。その余白込み音声から字幕を作るので、字幕・話者・SEの時計も同じクリップ先頭へそろえる。保存済みの編集データを描画するときは、選定・余白・重複整理・波形補助を繰り返さない。

元素材不存在、認証/通信失敗、実際の描画失敗、壊れた媒体、素材や保存先の取り違えは、補助処理の未達とは別の実行エラー。成功と偽らず記録する。参考画像だけの失敗は、完成動画の失敗へ昇格させない。

## 解像度と参考画像の扱い

通常CLIの `--render-profile preview|standard|full-hd` は、それぞれコミット済みの360p/720p/1080p設定を選ぶ。省略時の `config.landscape-long.example.json` は720pキャンバス。`--config-file` で別の設定を選ぶこともできる。両方指定した場合はrender-profileが設定ファイルを選ぶ。高解像度の素材を自動取得する指定ではない。

描画後の `contact-sheet.jpg` は見た目の修正を助ける参考資料で、自動監査結果ではない。全編を検査用に再デコードせず、既に生成した字幕イベントの時刻へ限定して最大3フレームを読む。時刻と実際のスタイル名を添え、見出し・色・文字の大きさを見比べられる形にする。字幕全文・同期・固有名詞の正しさを、この画像で確認済みとは扱わない。

画像は非公開result.zip内に保存する。可能なら同じ非公開Releaseへ `clip-001-contact-sheet.jpg` 等の単体assetも追加し、動画zipを回収せず画像だけ取得できるようにする。単体assetの追加に失敗しても、動画とアーカイブの保存成功を維持する。品質のpassedは引き続きnull、監査はnot_run。

今回の変更では、テスト・モデル要求・実動画制作・参考画像生成・映像検査を実行していない。実装・登録と実際の仕上がりを区別する。コード更新だけを理由に、既存の完成動画を作り直さない。

通常制作・修正・回収の入口は [統合経路ガイド](PRODUCTION_AND_REVISION.md)。Geminiへ渡す表現は [必読編集ルールブック](../src/clipforge/prompts/gemini_editorial_rulebook_ja.md)を参照。
