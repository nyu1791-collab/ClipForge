# 横動画の受入条件と未決事項

対象は同じ配信から作る、話題別の16:9・1920×1080動画3〜5本。Shortsは対象外。
実行手順は [AUDIO_FIRST.md](AUDIO_FIRST.md)、品質の規則と理由は [QUALITY_DECISIONS.md](QUALITY_DECISIONS.md)、計測の記録は [QUALITY_REVIEW.md](archive/QUALITY_REVIEW.md) を参照する。

## 設定と再現性

- `--config config.landscape.example.json` を明示する。横用設定は16:9、1080高、CPU/int8、`threads=2`、Whisper large-v3-turbo。全体の `threads` の既定は `0`（自動）で、横用の2は明示設定。URL経路のASRはColab GPUのCUDA/float16で行い、描画はColab CPUの `encode_threads=0`（全コア）を使う。
- 横字幕の表示延長目標・警告基準は7字/秒（2026-10-22、利用者の決定）。1行全角13字相当・最大2行・実フォント幅・字幕の重なりは独立に確認する。7字/秒の採用だけで、読みやすさの改善やNetflix SDHへの全面準拠とは呼ばない。
- 4/7/10字超過数、表示時間、画面超過、文頭の孤立語を記録する。`spoken_length()` は空白を除く文字数であり、行幅の半角換算とは別。文字数の数え方を変えた場合は同一条件の比較にしない。
- コードSHA、設定、ツール・フォント・モデルの版、入力・選定・ASRの識別情報、ASR再利用成否、段階別時間、出力寸法・尺・品質値・警告を記録する。再利用時間の短さだけでキャッシュhitと判定しない。
- 実動画・ASR・選定本文・詳細警告・素材パスは私有領域に置き、共有用は数値と識別情報に限る。公開する再現例は合成データを使う。

## 本数・話題・映像の受入条件

- 同じ入力から異なる話題の非重複3〜5本を作る。始まりの文脈・本題・結び、映像と発話の一致を人が確認する。語彙による話題分割や非重複の時刻だけでは、意味的な違いや完結を保証しない。
- URL経路の `review-draft.json` は未承認。候補映像を確認し、別の承認ファイルを作ってから描画する。静止画シートだけで視聴済みとはしない。
- すべて1920×1080、全復号、48 kHz、品質ゲート通過、ASS/SRT一致、警告一覧を満たし、人による内容と読みやすさの確認を行う。strict通過は警告0件や内容承認ではない。
- 横用の尺は20〜180秒。素材や話題が足りない場合は本数を水増しせず、未達理由を記録する。本文削除・字幕の重複・音声とのずれで基準を満たさない。
- ローカル動画の手動選定では、元動画秒数の区間と要求本数を一致させ、選定receiptの `provider=manual`・`generation_requests=0` を確認する。`batch` は複数入力用であり、同じ配信の話題別出力とは分ける。

## 口語とGeminiの受入確認

- 権利のある3〜5分の雑談サンプルで、孤立した終助詞、誤った文末、短すぎる字幕、語割れ推定の誤検知を確認する。保存済みASRを使い、原因を確認できた規則だけを変更する。公開テストには誤りを再現する合成例を使う。
- ローカル動画経路のGemini選定は独立して確認する。承認・鍵登録後、指定モデルで候補アップロード・状態確認・応答時間・使用トークン・返却モデル・後始末・選定JSONを記録する。候補ID、候補内区間、元動画への変換、尺、重複を検査する。
- `tools/check_gemini_connection.py` の診断成功を、選定生成の成功とは扱わない。実利用可否・無料枠・割当はその時点のアカウントで確認し、自動再試行や別モデル・有料版へのfallbackを行わない。

## 未決事項・未確認

- 180秒を超える話題を扱うか。拡張する場合は字幕とは別に、候補分割・選定検査・時間予算を見直す。
- 再現に使う実素材・保存済みASR・選定ファイル・非公開成果物の所在と対応付け。制御VMで重いASR・描画を実行しない。
- 実配信の口語での読みやすさ、正解との認識精度比較、要求本数を満たす素材での内容確認。
- Geminiの実選定の承認・鍵登録・AI Studioでのアカウント別割当と、実呼び出しの結果。
