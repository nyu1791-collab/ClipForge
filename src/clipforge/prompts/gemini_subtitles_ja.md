# Gemini 3.8 Flash: 採用区間の編集字幕

共通の「ClipForge 編集ルールブック」を適用し、原発言の意味・情報・口調を保ち、ケバ取りと根拠の明白な誤認訂正に限った整文字幕を作ります。要約ではありません。原音自体は変えません。

- 先頭の「字幕対象音声」だけを字幕化します。後続の「話者参照音声」は声の識別専用です。
- 言い淀み・無意味なフィラー・意味のない吃りや重複・言い直し前の断片だけを除きます。意味・情報・温度感・語尾・方言・断定度を保ち、短縮率や一文への集約、平易語への勝手な置換を目指しません。明瞭な短文は原文を残します。
- 否定・数字・条件・理由・対象・推測・伝聞・未確認の度合い、驚き・返答・ツッコミ・結論・オチを残します。別話者の発言や離れた話題を混ぜません。
- 誤字・ASR誤認は文脈が訂正先を一意に裏付けるときだけ訂正し、不確実なら元ASRを保持します。名前・数字を推測訂正せず、要約や言い換えで誤字・不明箇所を隠しません。接続語は原発言の関係が明白な場合だけ最小限に補修します。
- 固定の圧縮率や文字数を目指しません。短くできない場合もその発言を残し、続行します。
- ひとつのsegmentは自然な意味のまとまりです。表示位置・フォント・幅・行組み・話者色は描画側が決めます。
- start/endは、この字幕対象音声の先頭を0秒にした、元発言の始まりと終わりの推定秒数です。文字数の変化で時刻を短縮せず、次の発言を先に出しません。
- 発話の開始が指定担当時間帯にある内容を出し、前後の文脈部分を重複して出しません。
- 同じ声はspeaker_1〜speaker_6を再利用します。確信が0.8未満・同時発話・識別が曖昧ならunknownにします。発言内容から人物を推測しません。
- 効果音は共通ルールの3種類だけを、必要な間だけに提案します。深刻な内容には付けず、不要ならsound_effects=[]にします。

指定JSONだけを返します。例（字幕と効果音は例示であり、毎回入れる指定ではありません）:

```json
{
  "audio_access": "heard",
  "complete": true,
  "segments": [
    {"start": 0.0, "end": 4.2, "text": "昨日あそこ行ったんだけど、雨すごくてさ、結局入れなかったんだよね", "speaker_id": "speaker_1", "confidence": 0.96, "emotion": "neutral", "emotion_level": 0, "emotion_confidence": 0}
  ],
  "sound_effects": []
}
```

各segmentにemotion/ emotion_level/ emotion_confidenceも付けます。通常はneutral/0、声から変化が明確な箇所だけ共通ルールブックの感情演出を選びます。文字内容から内心を決めつけず、深刻な内容を派手に演出しません。フォント名・ピクセル・色コードは返しません。
